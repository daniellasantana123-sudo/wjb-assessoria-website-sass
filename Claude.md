  - Terceiro bug (reportado pelo usuário em 2026-08-30, testes E2E não pegaram este): ao clicar num item do header com submenu (mega menu ou `NavDropdown`) e mover o mouse pra baixo até o painel pra escolher uma ação, o menu fechava antes de conseguir clicar. Causa: o painel usa `top-full mt-3` (gap visual de 12px entre botão e painel); como o painel é `position: absolute`, ele não conta pro bounding box do `<div className="relative">` pai que tem `onMouseEnter`/`onMouseLeave` — então esse gap de 12px é uma "terra de ninguém" onde o mouse tecnicamente sai do elemento pai, disparando `mouseleave` antes do cursor alcançar o painel. Fix: uma `<div>` invisível (`absolute inset-x-0 top-full h-3`) preenchendo exatamente esse gap, como descendente DOM do mesmo pai — elimina a zona morta sem precisar remover o espaçamento visual. Playwright não pega esse tipo de bug porque `.click()` não simula o mouse atravessando o caminho até o alvo, só teleporta e clica.
